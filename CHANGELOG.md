**Status:** proposed local candidate, pending owner-approved first publication.

- Curated a clean public release with no inherited development history,
  credentials, private caches, raw local FITS/research datasets, or recovery
  reports.

  manifests.

- Documented DR1 compatibility assessment without integrating DR1 images or
  the 102-channel all-sky cube.
- Corrected the staged public README so it does not link to excluded private
  DR1 research artifacts.
